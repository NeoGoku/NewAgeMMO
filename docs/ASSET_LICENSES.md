# Asset-Herkunft
Alle Grafiken (Szenen, Charaktere, Monster, Item-/Skillicons, Effekte, App-Icon) und Töne (Musik, Soundeffekte) werden **zur Laufzeit prozedural** durch eigenen Code erzeugt (Canvas2D/WebAudio). Es werden keine fremden Bild-, Ton- oder Schriftdateien eingebunden; es werden Systemschriften verwendet. Damit gibt es keine Fremdlizenzen.
**Vorläufig:** Die prozedurale Optik ist ein Platzhalter-Niveau für die Alpha. Handgezeichnete/lizenzierte Endassets können später je Ort/Charakter ergänzt werden; jedes neue Asset muss hier mit Quelle und Lizenz eingetragen werden.
Abhängigkeiten (MIT/Apache): react, react-dom, vite, vite-plugin-pwa, ws, pg, tsx, typescript, @capacitor/*.
